DOM-based XSS: IndexedDB Entry Point

This page intentionally demonstrates a DOM-based XSS vulnerability where untrusted data is stored in IndexedDB and later rendered using innerHTML.

(output)


You can also inject the payload using the browser console (Copy-Paste it):

    indexedDB.open("xss_demo_db",1).onsuccess=e=>{
      const d=e.target.result,
            t=d.transaction("settings","readwrite");
      t.objectStore("settings")
       .put("<img src=x onerror=alert(1)>","profile")
    }
