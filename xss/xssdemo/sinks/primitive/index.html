Primitive JavaScript Sinks

Mini labs for the most common, stable browser sinks: DOM execution, URL execution, and JS execution.

Goal: find sink → trace source
Payloads: alert(1) (HTML/URL/JS)
Skill: read JS code & data flow

How to use

Workflow
1) Open a sink demo page
2) Try the Direct demo (source → sink, very clear)
3) Then solve the Puzzle (find the only input that reaches the sink)
4) Use DevTools → Sources and search for the sink string shown on the page

Quick map (tree)

DOM execution (12 labs)
├── HTML parsing: innerHTML, outerHTML, insertAdjacentHTML, write/writeln, srcdoc, template.innerHTML
├── Event handlers: setAttribute('on*'), on* property
├── DOM builders: createContextualFragment, DOMParser, appendChild(taintedNode)
└── Script text: script.text / script.textContent

URL execution (11 labs)
├── Navigation: location.* (location=, href, assign(), replace()), window.open, document.location
├── Script src: script.src + append
├── Frame: iframe.src
└── Other: a.href, form.action

JS execution (4 labs)
├── eval(), new Function()
└── setTimeout/setInterval(string)
